# 依赖说明（实验3 桌面物体自动分类整理）

> 对应《实验3 实验要求》§七提交材料第 1 项“完整 ROS 2 工程、Launch 文件和**依赖说明**”。

本工程是**一套任务控制核心、两条执行线**（详见 [`../README.md`](../README.md)）：

| | 仿真线 | 真机线 |
|---|---|---|
| 平台 | mechArm 270（Gazebo） | **RoboMaster EP 工程形态** |
| 中间件 | ROS 2 Humble | **无 ROS**（EP Python SDK 直连） |
| 依赖重量 | 需要 ROS2 环境 | **零 ROS 依赖**（只多一个 robomaster + 可选 opencv/ultralytics） |

**离线部分零第三方依赖**，任意装了 `python3` 的机器（Mac / Windows / Linux）都能跑；
ROS 2 部分**只在仿真机上**运行。真机线**不经过 ROS 2**，是纯 Python。

## 1. 运行环境

| 角色 | 平台 | 用途 |
|---|---|---|
| 离线开发/自测 | macOS / Windows / 任意 Linux | `sort_core`、`examples`、`tests`、`config_check.py`、真机线 `--dry-run` |
| 仿真运行 | Ubuntu 22.04 + **ROS 2 Humble**（Jetson Orin NX 或任意装了 ROS2 的机器） | 相机、识别节点、Gazebo 机械臂仿真、任务控制节点 |
| 真机运行 | 任意有 USB 口的机器（**不需要 ROS2**） | RoboMaster EP 工程形态 + USB 摄像头，`real/run_real.py` 一条命令起整链 |

- **Python**：3.8+（离线部分只依赖标准库；无 numpy / 无第三方包）。
- **ROS 2 发行版**：Humble（仿真线）。

## 2. 依赖清单（按层）

### 2.1 离线层（无需 ROS，无第三方依赖）

`sort_core/`、`examples/`、`tests/`、`config_check.py` 只使用 Python 标准库
（`json`、`math`、`os`、`sys`、`time`、`datetime`、`collections`、`argparse`、`unittest`）。

```bash
# 无需 pip install 任何东西
python3 -m unittest discover -s tests -t . -v
```

### 2.2 仿真线 ROS 2 层

| 依赖 | 来源 | 用途 |
|---|---|---|
| `rclpy` | ROS 2 Humble 自带 | 节点 / Action server / client |
| `sensor_msgs` | ROS 2 Humble 自带 | 相机图像 `Image` |
| `vision_msgs` | `sudo apt install ros-humble-vision-msgs` | `Detection2DArray` / `Detection2D` / `BoundingBox2D` / `ObjectHypothesis` |
| `cv_bridge` | `sudo apt install ros-humble-cv-bridge` | 仅识别节点（乙侧）图像转换用 |
| **`sort_msgs`** | **本工程 `ros2/sort_msgs/`** | `PickPlace` Action 接口，需自行 colcon 编译 |

> **版本注意（vision_msgs 新旧字段）**：老版 `ObjectHypothesis{class_id, score}`，新版为
> `class_probabilities: ClassProbability[]`（带类名）。本工程读取处用 `hasattr` 两头兼容，
> 但**动手前请先确认本机字段**：
> ```bash
> ros2 interface show vision_msgs/msg/ObjectHypothesis
> ```

### 2.3 真机线（EP，**不需要 ROS 2**）

| 依赖 | 来源 | 必需性 | 用途 |
|---|---|---|---|
| `robomaster` | `pip3 install robomaster`（大疆官方 Python SDK） | **必需** | 连 EP、底盘 `goto`、臂 `moveto`、夹爪开合 |
| `opencv-python` | `pip3 install opencv-python` | USB 相机必需 | `--camera cv2:0` 取帧；`--camera none/image:*` 时不需要 |
| `ultralytics` | `pip3 install ultralytics` | 仅 `--detector yolo` | 直接跑 `.pt` 权重；用乙交付的 `detect(frame)` 则不需要 |
| `ep/drive/rm.py` + `ep/config_ep.json` | **实验二** `mecharm-grasp-exp/ep/` | **必需** | EP 连接与运动原语封装（**故意不抄第二份**，两份驱动一定会漂） |

- 真机线**只用标准库 + 上表**；`sort_core/` 与 `real/` 中除 `camera.py` 的懒加载外无第三方 import。
- 三个可选依赖都是**懒加载**：没装 opencv 时 `--camera none` 照跑，没装 ultralytics 时
  `--detector file` 照跑 —— 报错只在你真的用到那条路径时出现。

## 3. 安装与编译步骤（仿真线）

```bash
# 1) ROS 2 基础 + 消息包（若实验一已装 ROS 2，通常只差 vision_msgs/cv_bridge）
sudo apt update
sudo apt install -y ros-humble-vision-msgs ros-humble-cv-bridge

# 2) 编译本工程的接口包 sort_msgs（只装消息）
mkdir -p ~/ws_mecharm/src && cd ~/ws_mecharm/src
cp -r <本工程>/exp3/ros2/sort_msgs .          # 或软链到源码目录
cd ~/ws_mecharm
colcon build --packages-select sort_msgs
source install/setup.bash

# 3) 验证接口已生成
ros2 interface show sort_msgs/action/PickPlace
```

> `ros2/task_control/` 下的文件是**直接 `python3 <file>` 运行**的脚本（沿用实验二 c4_2 风格），
> **不是** colcon 包，无需 build；`ros2/sort_msgs/` 才是需要编译的包。

**真机线无需任何编译步骤** —— 装完 SDK 直接 `python3 real/run_real.py`。

## 4. 跨工程依赖（实验一 / 实验二）

| 依赖 | 来自 | 用在哪条线 | 说明 |
|---|---|---|---|
| cup/mouse 检测权重（`.pt`/`.engine`） | **实验一** `masai114514/object_detection_lab`（公开） | 两条线都用 | 识别侧（乙）复用其训练模型；仿真期可用 mock，消息口径一致 |
| `C4Driver` 运动原语 | **实验二** `masai114514/mecharm-grasp-exp`（私有） | **仅仿真线** | 仿真执行者 `C4PickExecutor` 用；真机线不依赖它 |
| `ep/drive/rm.py`（EP 驱动） | **实验二** 同仓库 `ep/` | **仅真机线** | 真机执行者 `EPPickExecutor` 的 `rm`；复用同一份，不另抄 |

> `real/ep_backend.py` 会 `import ros2.task_control.exec_contract` —— 这不是笔误，
> `exec_contract.py` 是**故意写成 ROS-free** 的（只有 `sort_core` 依赖），这样两条线的
> 执行者都从**同一处**取 `PickExecutor` ABC 与 `resolve_goal`，契约不会分叉。

## 5. 运行方式

```bash
# 离线（任意机器）
cd exp3 && python3 examples/run_demo.py --mode happy

# 仿真线：先 source ROS 2 + 工作区（sort_msgs 已 build），再按 ros2/task_control/README.md 拼装
source /opt/ros/humble/setup.bash
source ~/ws_mecharm/install/setup.bash
python3 ros2/task_control/pick_place_server.py --executor stub   # 冒烟时序

# 真机线（无 ROS；演练用 --dry-run，真机去掉它）
python3 real/run_real.py --config-dir config_real --dry-run \
        --camera none --detector mock --assume-judge --no-pause
```
