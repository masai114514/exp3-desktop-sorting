# EP 机械臂单次向上 5 毫米测试

这是 v4 夹爪开合检查之后的独立机械臂小步测试工具，使用现有 Windows Python 3.11。
全部解压到新的 `EP_Arm_5mm_Test_v2` 文件夹即可；不需要安装依赖或复制进 v4。v4 的日志请保留。

已知现场进度（来自用户 2026-09-13 的日志）：

- v4 夹爪张开/闭合命令和停止应答均为 True，操作员两次填写 y，正常退出。
- 机械臂已在 RoboMaster App 中校准；最新只读检查 CONNECT_OK，电量 85%，校准后 SDK 坐标 [74, 57] mm。
- 照片里机器人在有显示器和电线的桌面上。本次点动前应先关机，将整车搬至空旷、平整地面；搬动时托住底盘，不提拉机械臂。

## 现场操作

1. 关闭已结束的测试窗口。将机器人移到平整空地，夹爪空载，机械臂上方与周围保持空旷，手和电线离开连杆及夹爪。确保移动时线缆不被拉紧。
2. 开机并等开机动作结束，笔记本连接机器人热点 RMEP-21C392。关闭其他 EP 控制会话。
3. 双击 `04_arm_5mm_test.cmd`，应显示 `Arm 5mm test version: 2`。
4. 程序先读取机械臂和电量；看到 `arm>` 后，只有确认上面的现场条件才输入 `u` 回车。输入 `q` 可在发送移动前退出。
5. 程序重新读取姿态，再发出一次 `robotic_arm.move(x=0, y=5)`。这是相对向上 5 mm 的指令；动作完成后还会继续观察约 2 秒。
6. 观察机械臂是否向上微动并停住，在观察问题处如实输入 `y`（看到且停住）、`n`（没动或异常）、`u`（不确定）。不要为了通过检查填写 y。
7. 程序自动结束本轮，不会自动回落或重复点动。保持 Wi-Fi 和机器人供电，等 `DISCONNECTED` 和最终结果出现，再按任意键关闭窗口。发送完整输出及本次 `logs/arm_时间戳/result.json`。

如果出现异常运动、持续顶住或卡住，关闭机器人电源，不用手阻挡。所用 SDK 的机械臂接口没有
公开的暂停方法；Ctrl+C、动作超时或断开连接都不能当作物理停止确认。本程序不调用只改变本地
状态的私有 `_abort()`，也不以“回中”或另一条移动命令代替急停。

## 读数与结果

SDK 的 x/y 是机械臂坐标，不是夹爪离地高度。程序以本次新读取的位置为起点，
校准后若起点仍接近 [74, 57]，加上相对指令后的预期读数约为 [74, 62] mm，需以实测为准。
搬动整车和重启后可能有变化，因此本包不把昨天/上一轮的读数直接用作绝对目标。

| 字段 | 含义 |
| --- | --- |
| ARM_BEFORE / ARM_AFTER | 指令前、SDK 动作完成后采集的稳定坐标 |
| EXPECTED_AFTER | 起点加上相对位移后的预期值，不是实测值 |
| ACTION_COMPLETED | 动作等待接口是否返回 True；还必须结合 ACTION_SUCCEEDED |
| ACTION_SUCCEEDED | SDK 是否报告动作成功 |
| ARM_DELTA | 后坐标减前坐标，预期接近 [0, 5] mm |
| POSITION_CHECK | x 变化不超过 2 mm、y 变化在 3–7 mm 之间的粗略核对 |
| ARM_STEP_OBSERVATIONS_RECORDED | SDK 成功、坐标变化符合粗略核对，且操作员填写看到向上微动并停住 |
| NOT_READY | 本轮未发送移动，需查看读数或电量错误 |
| MOTION_UNCONFIRMED / NEEDS_REVIEW | 动作或实物观察未完成核对；不自动重试 |
| NO_MOTION_REQUESTED | 输入 q，没有请求移动 |

这是为本次校准姿态准备的诊断：电量至少 30%，起始坐标每轴与 [74, 57] 相差不超过 10 mm；
输入 u 期间姿态若变化超过 2 mm，也不发命令。这些是本工具的检查阈值，**不是厂商规定的
可达范围、电池工作界限或精度指标**，也不判断现场碰撞风险。
启动、动作前和动作后均读取新鲜、不同批次的稳定样本；不使用旧坐标充当运动后读数。

只做一次小步，不反复重启来累加位移。此工具没有方向选择、自动返回、底盘移动和夹爪开合，
也没有使用原抓取包的占位绝对坐标。SDK `move(x, y)` 不提供速度参数，本工具不声称调低了速度。

离线导入检查：`python .\arm_5mm_test.py --offline`。不加参数也默认离线。

## 实现依据与验证边界

已核对官方接口：相对移动 x 向前为正、y 向上为正，单位 mm；移动返回 Action，等待完成后
仍需检查成功状态。此包内的 vendor SDK 沿用用户已验证的 v4 控制通信源码。

- 官方接口：https://robomaster-dev.readthedocs.io/en/latest/python_sdk/robomaster.html#robomaster.robotic_arm.RoboticArm.move
- 包内对应源码：vendor/robomaster/robotic_arm.py、vendor/robomaster/action.py。
- 软件验证见 `验证记录.txt`。离线测试不能代替用户的 Windows/EP 现场验证。

本工具只用于首次机械臂方向和小位移检查，尚不构成抓取低点、抬高点、A/B/HOME 标定或 C5 验收。
